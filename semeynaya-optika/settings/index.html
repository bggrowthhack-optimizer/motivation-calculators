Нормы расчёта

Оклад, грейды % от выручки по плану филиала, норма прозвона базы, ограничитель по чеку. Меняешь → «Сохранить» → калькулятор в этом браузере считает по-новому.

Важно: правки сохраняются только в этом браузере (у статического сайта нет общего хранилища). Консультанты у себя видят значения по умолчанию. Чтобы новые нормы стали боевыми для всех — передай JSON снизу разработчику, он впишет их в код и задеплоит.
