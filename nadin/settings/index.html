Нормы расчёта

Пороги показателей, ставки часа и суммы доплат. Меняешь значение → «Сохранить» → калькулятор в этом браузере начинает считать по новым нормам.

Важно: правки сохраняются только в этом браузере (у статического сайта нет общего хранилища). Сотрудники, открывшие калькулятор у себя, продолжают видеть значения по умолчанию. Чтобы новые нормы стали боевыми для всех — передай JSON снизу разработчику, он впишет их в код и задеплоит.
