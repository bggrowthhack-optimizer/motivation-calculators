# Калькуляторы мотивации

Сайт с калькуляторами зарплаты для клиентов ОВС (Команда Роста). Сотрудник
открывает свой калькулятор, вводит реальные показатели (ползунком или прямо
цифрами в поле), фиксирует их как точку отсчёта — и дальше смотрит вживую,
как изменение конкретного показателя (доля ВТЛ, средний чек, выручка и т.д.)
меняет итоговую зарплату. Дизайн намеренно повторяет токены главного продукта
(Оптимайзер), а не собственный стиль — подробности в [`CLAUDE.md`](./CLAUDE.md).

**Каждый клиент получает только свою прямую ссылку `/<client>/` — на сайте
нет общего меню или списка клиентов**, чтобы клиенты не могли зайти в чужой
калькулятор. `robots.txt` дополнительно блокирует индексацию поисковиками.
Репозиторий тем не менее публичный — подробнее об ограничениях этого подхода
и о том, как добавить нового клиента, см. [`CLAUDE.md`](./CLAUDE.md).

```
/
├── robots.txt
├── assets/
│   ├── engine.js       движок, общий для всех клиентов
│   └── engine.css      общая тема и вёрстка
└── <client>/
    └── index.html      своя формула и свои поля клиента
```

Статика без бэкенда — весь расчёт на клиенте, ничего никуда не отправляется.
Хостинг — GitHub Pages, деплой автоматический при пуше в `main`.
