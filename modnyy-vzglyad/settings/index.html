Нормы расчёта

Оклады, грейды % от выручки, KPI месяца. Меняешь → «Сохранить» → калькулятор в этом браузере считает по-новому.

Важно: правки сохраняются только в этом браузере (у статического сайта нет общего хранилища). Сотрудники у себя видят значения по умолчанию. Чтобы новые нормы стали боевыми для всех — передай JSON снизу разработчику, он впишет их в код и задеплоит.
